# Studio fonts

The renderer uses the original, unmodified Open Sans Regular, Semibold and Bold files from Debian's `fonts-open-sans` package version `1.11-2`, and DejaVu Sans Mono from `fonts-dejavu-core` version `2.37-8`. These exact files are bundled to keep text size and wrapping consistent in the published videos. Run `sha256sum -c SHA256SUMS` in this directory to verify them.

Open Sans copyright notices are in `OpenSans-LICENSE.txt` and its full Apache License 2.0 is in `Apache-2.0.txt`. The Bitstream Vera license and DejaVu modification notices are in `DejaVu-LICENSE.txt`.
